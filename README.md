# BrickCraft 3D

브라우저에서 **93종의 레고 시스템 브릭**으로 3D 모델을 조립하고, 조립 순서를 애니메이션 **GIF**로 내보내는 웹 스튜디오입니다.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fknoxxr%2Fbrickcraft-3d)

## 주요 기능
- **93종 레고 브릭 3D 라이브러리**: 기본 브릭, 코너, 원통/콘, 플레이트, 점퍼, 타일, 그릴/잉곳, 슬로프/치즈/역슬로프/곡면, 아치/돔, 창문/문/울타리/계단/벽돌/패널, 테크닉/SNOT/브래킷/턴테이블, 바퀴/흙받이/앞유리/스포일러/자연 파츠
- **24종 레고 컬러**: 불투명 ABS, 메탈릭 골드, 투명 유리/불꽃
- **조립 순서 타임라인**: 드롭 조립 애니메이션 재생, 단계별 이동 및 층별 자동 정렬
- **GIF89a 내보내기**: 해상도 선택(`480×360` / `640×480` / `800×600`), 드롭 조립 / 스냅샷 / 360° 턴테이블, 단계 HUD 오버레이 지원
- **라이트/다크 테마 & JSON 저장/불러오기**

## Vercel 배포
위 **Deploy with Vercel** 버튼을 클릭하거나 로컬에서 아래 명령을 실행하세요.

```bash
npx vercel --prod
```
