# BrickCraft 3D

브라우저에서 **103종의 레고 시스템 브릭 · 미니피규어 · 커스텀 캐릭터**로 3D 모델을 조립하고, 조립 순서를 **GIF · 60fps 영상 · 투명 PNG · 3D 프린팅/편집 파일(`.STL`/`.OBJ`) · 공식 스타일 조립 설명서(PDF/BOM)**로 내보내는 올인원 3D 레고 스튜디오입니다.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/import?s=https%3A%2F%2Fgithub.com%2Fknoxxr%2Fbrickcraft-3d)

## 주요 기능
- **103종 레고 브릭 & 피규어 라이브러리 + 24종 컬러**: 기본 브릭, 코너, 원통/콘, 플레이트, 점퍼, 타일, 그릴/잉곳, 슬로프/치즈/역슬로프/곡면, 아치/돔, 창문/문/울타리/계단/벽돌/패널, 테크닉/SNOT/브래킷/턴테이블, 바퀴/흙받이/앞유리/스포일러/자연 파츠 + **9종 레고 캐릭터·반려동물 & 나만의 커스텀 미니피규어 빌더** (모자·헤어·헬멧·왕관 / 5종 표정 / 6종 소품 / 부위별 색상 커스텀)
- **사진 → 레고 모자이크(픽셀 아트) 변환기**: 이미지 업로드만으로 24종 레고 컬러에 맞춘 `16×16` / `24×24` / `32×32` 모자이크(평면 액자 또는 수직 벽화, Floyd-Steinberg 디더링) 자동 생성
- **로컬 자동 저장 & 내 작품 갤러리**: 작업 내용 실시간 자동 저장/복원 + WebGL 썸네일 포함 다중 슬롯 작품 보관함
- **프로급 3D 편집 도구**:
  - **한영 무관 단축키**: 놓기(`B`/`1`), 색칠(`P`/`2`), 지우기(`X`/`3`), 3D 드래그 이동(`G`/`4`), 다중·박스 선택(`V`/`5`), 스포이드(`I`/`6`), 연속 그리기(`C`), 회전(`R`), 대칭(`M`), 단축키 치트시트(`?`)
  - **연속 그리기 배치 (`C`)** & **드래그 영역 다중 박스 선택 (`V`)**
  - **층별 단면 투시 슬라이서 (Cutaway Slicer)** & **3D 스터드 정렬 십자 가이드라인**
  - **조명 스튜디오 프리셋 (낮 / 노을 / 밤 네온)**: 밤 모드에서 투명 유리·불꽃·크리스탈·바이저·골드 발광(Emissive) 효과
  - **실시간 그림자(16-bit Shadow Map) · 모서리 윤곽선 · 대칭(미러) 모드 · 베이스판(`16`/`24`/`32`)**
- **조립 순서 편집 & 올인원 내보내기 스튜디오**:
  - **단계별 자막(메모) 편집 (`✎`) & 드래그 앤 드롭 순서 변경** (`1브릭씩` / `층별 묶기` / `커스텀 스텝`)
  - **GIF89a · 60fps 영상(WebM/MP4) · 투명 PNG · 조립 설명서(PDF/PNG & BOM)**: 단계별 자막과 부품 콜아웃 오버레이 자동 포함
  - **3D 모델 파일 내보내기 (`.STL` / `.OBJ`)**: 실제 레고 실측 규격(`1 스터드 = 8.0 mm`) Binary STL(3D 프린팅) 및 Wavefront OBJ 추출
- **공유 · 모바일 · 사운드**:
  - **압축 URL 링크 공유**, **모바일 터치 핀치/팬 & 드로어**, **Web Audio 합성 레고 클릭 효과음**, **PWA 앱 아이콘**
