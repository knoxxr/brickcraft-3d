# BrickCraft 3D

브라우저에서 **93종의 레고 시스템 브릭**으로 3D 모델을 조립하고, 조립 순서를 **GIF · 60fps 영상 · 투명 PNG · 공식 스타일 조립 설명서(PDF/BOM)**로 내보내는 올인원 3D 레고 스튜디오입니다.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/import?s=https%3A%2F%2Fgithub.com%2Fknoxxr%2Fbrickcraft-3d)

## 주요 기능
- **93종 레고 브릭 3D 라이브러리 & 24종 컬러**: 기본 브릭, L자 코너, 원통/콘, 플레이트, 점퍼, 타일, 그릴/잉곳, 슬로프/치즈/역슬로프/곡면, 아치/돔, 창문/문/울타리/계단/벽돌/패널, 테크닉/SNOT/브래킷/턴테이블, 바퀴/흙받이/앞유리/스포일러/자연 파츠 + 메탈릭 골드 & 투명 유리/불꽃
- **조립 순서 스텝 그룹핑**: `1브릭씩` / `층별 자동 묶기` / `커스텀 스텝 그룹` 지원
- **공식 설명서 스타일 Parts Callout & 내보내기 스튜디오**:
  - **GIF89a 내보내기**: 드롭 조립 / 단계별 스냅샷 / 360° 턴테이블 + 단계별 부품 콜아웃 오버레이
  - **60fps 영상 내보내기**: WebM/MP4 실시간 60fps 조립·회전 영상 녹화
  - **투명 배경 PNG 스냅샷**: 썸네일·발표자료용 고해상도 알파 채널 PNG 렌더링
  - **조립 설명서(PDF/PNG) & 부품 목록(BOM)**: 전체 부품 개수 자동 집계 + 단계별 3D 가이드 인쇄/PNG 시트 저장
- **3D 편집 도구 & 비주얼**:
  - **대칭(미러) 조립 모드 (`M`)**: X축 / Z축 / X+Z 4방 대칭 실시간 고스트 & 동시 배치
  - **실시간 그림자(Shadow Map) & 모서리 윤곽선 모드** 토글
  - **베이스판 크기 전환 (`16×16` / `24×24` / `32×32`)** & **스포이드 (`I` / `Alt+클릭`)**
  - **다중 선택 · 그룹 이동 · 복제(`Ctrl+D`) · 일괄 색칠 · 스텝 묶기**
- **공유 · 모바일 · 사운드**:
  - **압축 URL 링크 공유**: 서버 없이 모델 전체를 해시 URL에 압축해 링크로 즉시 공유
  - **모바일 터치 제스처**: 핀치 줌, 두 손가락 팬, 접이식 좌우 드로어
  - **Web Audio 합성 브릭 효과음**: 레고 결합 "딸깍" 사운드(켜기/끄기 토글)
